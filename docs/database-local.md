# 本机数据库部署与数据保存

当前版本通过本机 HTTPS 服务访问 MySQL `home-app`，APK 不含数据库密码。监听地址为 `127.0.0.1:8787`，不对局域网或公网开放。

## 使用

电脑保持 MySQL 与后端运行。模拟器中打开新版应用，注册自己的账号，然后到「我的 → 数据与同步 → 备份并导入旧本机记录」。首次导入会备份完整旧记录，并将原主健康档案作为当前账号的个人健康资料；原 localStorage 不删除。仅允许导入到尚无修改的家庭与个人档案，防止覆盖已有数据。没有替用户创建正式账号。

今后新增或修改账户、流水、人情、分类、房屋、地址、健康资料、体重、饮食及金额隐藏偏好，均自动写入 MySQL。顶部显示保存结果，只有后端确认成功才显示「已保存到数据库」。统计由数据库加载的流水实时计算，不另存一份容易失效的统计结果。照片分析确认后的食物、份量、热量等记录保存到数据库；原始识别照片仍为临时文件，不构建云相册。模型连接信息与密钥继续只在 Android 本机加密保存。

家庭成员、邀请码由后端管理。健康及偏好按登录账号隔离，家庭账本在同一家庭成员间共享。原有“个人资产”是家庭账本内账户范围的展示规则，不代表额外的私密账本权限。

断网时已登录应用仍可编辑，修改进入按账号和服务地址隔离的加密草稿，失败不会显示数据库已保存。恢复网络后从「数据与同步」重试。若应用重启时后端不可达，需恢复连接并登录后重试，当前版本不支持离线解锁。冲突时不会覆盖其他设备的数据，可保留草稿并加载最新数据库，导出草稿后手动核对。共享列表在前台约每10秒自动检查其他成员更新，进入共享页面和返回应用也会检查。编辑表单、有未保存修改或冲突时暂停刷新，避免覆盖输入；也可使用该按钮手动重新加载。

## 重启服务

在项目根目录执行（初次环境先安装 `server/requirements.txt`）：

```powershell
python -m pip install -r server/requirements.txt
python tools/setup-local-tls.py
./tools/start-local-server.ps1 -Python '你的python.exe完整路径'
adb -s emulator-5554 reverse tcp:8787 tcp:8787
```

现有电脑已安装依赖、生成证书并启动服务。重启电脑后需重新启动服务；模拟器或 ADB 重启后需恢复端口转发。启动脚本隐藏后台窗口，记录 PID 与日志到 `.local-server/`。默认 Python 路径已配置为当前电脑运行时，可用参数指定其他解释器。

服务只公开 `web/` 静态文件和 `/api/` 接口。`本地数据库连接.md`、`api-key.txt`、证书私钥与日志均在网站目录外，且被 Git 忽略。不要把项目根目录的开发对照 HTTP 服务暴露到网络。Android 调试包只为 localhost 信任本机公钥证书；更换证书需重新构建 APK。生产部署需另配服务器、公信 HTTPS 域名、生产签名及数据库备份运维。

## 表结构与一致性

1.5.1 新增 `app_address_photos`，用 MySQL BLOB 保存地址图片，地址记录保存图片编号。每个地址最多9张，服务端缩放至最长边1280px并重新编码 JPEG，剥离原图元数据。读取和引用均验证家庭权限。删除按钮在保存地址后解除关联；未关联图片在7天后、下次上传时回收，每个家庭上限200MB。图片上传需要后端在线，上传完成后还需保存地址；上传失败会保留已填写内容与成功上传的图片。

- `users / families / members / invite_codes`：真实账号密码哈希、家庭成员关系和邀请码。
- `app_family_data`：每个家庭一行 MySQL JSON 文档，存放账户、流水、人情、分类及样式、房屋、地址。
- `app_personal_data`：每个用户一行 MySQL JSON 文档，存放个人健康与偏好。
- `app_sessions`：仅存会话令牌的 SHA-256 哈希与过期时间。
- `app_write_receipts`：保存请求编号、内容哈希和结果，供重试去重。
- `app_legacy_backups`：每个账号首次导入前的完整旧数据备份。

业务记录使用 MySQL JSON 文档持久化，并不是逐笔写入旧 `accounts / ledger_entries` 表。旧表保留兼容原 Python 业务层，应用不混用两套数据源。家庭与个人分别有版本号，一次保存同事务提交，修改冲突返回 409、整笔回滚。请求重试使用相同编号和内容，不重复入账。当前适合个人与小家庭使用，文档和请求大小有限制，不是高并发大规模账务系统。

## 验证与备份

```powershell
python -m unittest tests.test_cloud_database -v
npm test
```

数据库测试真实连接本机 MySQL，使用随机账号，结束仅清理本次创建的账号。Android `DatabaseSmokeInstrumentation` 验证真实 HTTPS、注册、空页面、账户与流水、健康记录、重启恢复、加密草稿及丢失响应后的重试。测试输出 `TEST_UID` 后可用 `python -m tools.cleanup-database-smoke <ID>` 清理该专用账号（会验证其测试身份）。

「导出当前记录备份」用于可读业务备份；「导出保留的草稿」用于冲突核对。它们不含密码、模型密钥或会话令牌。正式长期使用前，应为整个 MySQL 数据库配置定期备份并验证恢复；本版本未创建自动备份计划。

## 自定义分类图标（1.5.3）

分类添加与编辑共用类型布局。上传图标后可拖动、缩放并裁切为256×256方形，确认后写入图片表，保存分类完成关联。categoryLooks 数组的可选第四项为图片编号，仍按家庭验证权限。内置图标沿用三项格式；切换回内置图标会解除该分类的自定义图标关联。图片回收同时检查地址和分类引用。

## 家庭互通（1.5.4）

分类及自定义图标、人情、房屋、地址及图片均按家庭共享。同一家庭的管理员和普通成员均可新增、修改这些记录，个人健康与偏好仍按用户隔离。只有通过邀请码加入同一家庭的账号才能互通；新注册默认建立独立家庭。自动刷新仅在前台安全的列表页面运行，失败不阻止本机编辑。
